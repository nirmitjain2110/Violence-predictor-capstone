Module 1: The Spatio-Temporal Violence Predictor
To meet your requirement for a lightweight architecture suitable for edge-cloud computing, you should avoid computationally heavy 3D CNNs.
Spatial Feature Extraction: Pass incoming frames through a lightweight 2D CNN like MobileNetV3.
Temporal Attention: Instead of standard pooling, implement a Temporal Attention Module (TAM) that weights the importance of specific frames over a 16-frame window.
Behavioral Embedding: This creates a feature vector representing the physical dynamics of the scene (e.g., rapid, erratic movements).
Module 2: Audio Stream Analysis
Relying on video alone in uncontrolled surveillance environments leads to false positives. Audio serves as a critical secondary validation metric.
Preprocessing: Convert the raw audio stream into Mel-spectrograms.
Sequence Modeling: Feed these spectrograms into a Long Short-Term Memory (LSTM) network as outlined in your project scope.
Audio Embedding: The LSTM will output a feature vector representing aggressive acoustic anomalies (e.g., raised voices, sudden loud noises).
Module 3: Parallel Multi-Class Weapon Detector
Most existing literature focuses exclusively on firearms. Your system needs to be robust against various threats and false alarms.
Detection Engine: Implement a lightweight, real-time object detector like YOLOv9-tiny.
Class Definitions: Train the model on custom datasets to detect firearms, knives, and blunt objects.
Confusion Classes: Crucially, include a "confusion object" class in your training data (e.g., smartphones, wallets, water bottles) to explicitly teach the model what not to flag, minimizing false alarms.
Module 4: Multi-Modal Fusion and Early Warning Engine
This is where the novelty of your project truly lies: moving from detection to prediction with a lead-time metric.
Attention-Based Fusion: Concatenate the embeddings from the Video Stream, Audio Stream, and the confidence scores/bounding box data from the Weapon Detector.
Prediction Mechanism: Pass this fused vector through a final predictive network layer. Instead of a simple binary classification of current violence, train the model to output a future probability using the following function:
$$P(V_{t+\Delta t}) = \sigma(W \cdot F_{fusion} + b)$$
Lead-Time Metric: $P(V)$ represents the probability of violence occurring, and $\Delta t$ represents your lead time (e.g., predicting an incident 3 to 5 seconds before a physical strike occurs).
Recommended Implementation Stack
Deep Learning Framework: PyTorch (excellent for custom attention mechanisms and multi-modal fusion).
Weapon Detection: Ultralytics (YOLOv9/YOLOv10).
Edge Optimization: Use TensorRT or ONNX Runtime to quantize your models (FP16 or INT8) so they can run smoothly on edge devices like NVIDIA Jetson Nano or Orin Nano.






The core novelty of this framework lies in four specific architectural and methodological contributions that directly address the critical gaps identified in current video surveillance literature:
Predictive Lead-Time Metric ($\Delta t$): While existing research focuses strictly on reactive violence detection during or after an incident occurs, this architecture models a predictive probability score $P(V_{t+\Delta t})$ to forecast violence seconds before physical conflict takes place.
Audio-Visual Cross-Attention Fusion: Current surveillance frameworks rely almost exclusively on visual streams. Fusing spatial-temporal visual features with Mel-spectrogram audio representations (via LSTM) provides a multi-modal secondary validation layer to filter out visual-only false alarms.
Extended Weapon Taxonomy & Confusion Class Mitigation: Existing models suffer from a heavy firearm-only bias. This design expands detection to knives and blunt objects, while introducing an explicit "confusion object" class (phones, wallets, bottles) during training to teach the network to reject false positive threats.
Lightweight Edge-Optimized Spatio-Temporal Pipeline: Instead of utilizing computationally expensive 3D-CNNs that struggle on edge hardware, the video stream combines a lightweight 2D-CNN (MobileNetV3) with a custom Temporal Attention Module (TAM) to achieve real-time inference on imbalanced CCTV footage.
